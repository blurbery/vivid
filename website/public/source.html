Download

Download .tar.gz or download .zip. Both are free and need no account. Each has everything in Vivid’s repository at that commit: the app source, the project specs, Vivid’s engine patches, the build instructions and THIRD_PARTY_NOTICES.md, which lists every third-party component with its version, licence and source.

If Settings > About shows “(modified)” beside the commit, that build was made with local changes that weren’t published, and this is the commit it started from.

This link doesn’t name a build’s source commit. In Vivid, Settings > About > Open Source Licences > Source for this build opens this page for the exact commit your build was made from.

Lucid Engine

Vivid plays media with Lucid Engine, a package of mpv, FFmpeg and other libraries built by Vivid’s own pipeline. Its corresponding source is the engine/ folder of the Vivid commit the engine release was built from: the pipeline, the upstream sources pinned by URL, commit and checksum, the build configuration and every patch. For Lucid Engine 0.1.0 that is the lucid-engine-0.1.0-source tag: download .tar.gz or download .zip. THIRD_PARTY_NOTICES.md in each build’s source names the engine release it uses and the commit that release was built from, and docs/cores/lucid-engine-build.md explains how to build it.
