Component: Rust standard library (compiled into libdovi) and the crates.io crates built into it
Version: 1.98.0 (tag 1.98.0, commit 88d9e12ae178fab0fb5cc050a94da85685d449ea)
Source: https://github.com/rust-lang/rust/tree/88d9e12ae178fab0fb5cc050a94da85685d449ea
SPDX: MIT OR Apache-2.0 (text included: MIT)
Note: Crate set: the crates.io crates the standard library is built from for Apple targets, at the versions locked in library/Cargo.lock at the tag, with the backtrace feature the Rust project's release builds enable. The same ten crates are present in the shipped ios-arm64 and tvos-arm64 Libdovi archives of Lucid Engine 0.1.0. The lock file's other crates are for other targets (WASI, UEFI, SGX, Hermit, Windows and others), tests, libtest, proc_macro or build scripts, and are not compiled into the standard library for Apple targets; foldhash is locked but not built, because the standard library turns off hashbrown's default features.
Note: Texts are taken from each crate's published .crate archive on crates.io, checked against the SHA-256 in library/Cargo.lock; the git commit is from the archive's .cargo_vcs_info.json. For dual or triple licensed crates the MIT text is included.
Note: libc appears twice in libdovi: 0.2.185 below, built into the standard library, and 0.2.172, which libdovi uses itself (see libdovi-MIT).
Note: The standard library's in-tree crates (core, alloc, std, std_detect, panic_unwind, unwind and compiler_builtins) are part of the Rust source above and are covered by its COPYRIGHT and licence files.
